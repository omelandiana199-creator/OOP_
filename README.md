# Лабораторна робота №1
**Тема:** Класи. Основні їх елементи. Інтерфейси. Суть та особливості

**Мета роботи:** Отримати практичні навички для розробки програм з використання класів та інтерфейсів у мові Java.

**Завдання:**
Згідно з варіантом №4, необхідно розробити модель прийому замовлень у харчувальні. Розроблена модель повинна містити не менше шести класів із глибиною ієрархії мінімум три рівні. Кожен клас має бути розміщений в окремому файлі. До основної моделі вимагається додати та імплементувати два інтерфейси. У рамках математичної задачі необхідно написати метод, який перевіряє, чи є число простим, а також функцію для фільтрації списку чисел, залишаючи в ньому тільки прості.

**Опис виконання роботи:**
Відповідно до поставленого завдання, було спроєктовано та програмно реалізовано об'єктно-орієнтовану модель прийому замовлень у харчувальні. Архітектуру моделі побудовано на базі ієрархії з шести класів, глибина успадкування якої становить три рівні. З метою дотримання стандартів організації коду, кожен створений клас було винесено в окремий файл. Додатково архітектуру було розширено: створено та імплементовано два інтерфейси, що доповнюють функціонал основних об'єктів. Окремим етапом стала алгоритмічна реалізація математичної задачі, під час якої було розроблено метод перевірки числа на простоту та інтегровано функцію фільтрації списку чисел, що залишає виключно прості значення.

**Висновок:**
У результаті виконання лабораторної роботи було успішно застосовано та закріплено практичні навички розробки програм із використанням класів та інтерфейсів у мові Java. Завдяки проєктуванню моделі прийому замовлень у харчувальні було детально досліджено механізми успадкування та особливості побудови багаторівневих ієрархій класів. Винесення кожного класу в окремий файл на практиці довело необхідність чіткої структуризації програмного коду. Процес імплементації інтерфейсів наочно продемонстрував гнучкі підходи до розширення функціональності об'єктів без зміни їх базової ієрархії. Водночас було вдосконалено навички розробки алгоритмів шляхом програмної реалізації методів перевірки та фільтрації простих чисел. Отримані знання є необхідною базою для подальшого проєктування надійного об'єктно-орієнтованого програмного забезпечення.
